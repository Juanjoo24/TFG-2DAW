👟 Proyecto Final 2º DAW – Tienda de zapatillas

Este es mi proyecto final de 2º de Desarrollo de Aplicaciones Web (DAW), una tienda online de zapatillas en la que los usuarios pueden explorar productos, buscarlos fácilmente, añadirlos al carrito y realizar compras de forma sencilla.

Además, la plataforma permite el registro de usuarios, aunque este no es obligatorio para poder realizar compras.
